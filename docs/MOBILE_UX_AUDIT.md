## Enrichments Applied

### 1. Dialog → Bottom Sheet on Mobile

**Before**: Dialogs rendered as centered modal overlays at all breakpoints, requiring users to reach up to tap the close button and providing poor content visibility on small screens.

**After**: On screens below `sm` (640px), dialogs render as bottom sheets — anchored to the bottom of the viewport with rounded top corners, slide-up animation, and safe area bottom padding. A drag handle indicator provides visual affordance. Close button remains accessible.

| Aspect    | Detail                                                                                   |
| --------- | ---------------------------------------------------------------------------------------- |
| Files     | `dialog.tsx`, `confirm-dialog.tsx`                                                       |
| Pattern   | iOS action sheet / Material bottom sheet                                                 |
| Animation | `slide-in-from-bottom-[10%]` on mobile, `zoom-in-95 + slide-in-from-top-[2%]` on desktop |
| Safe area | `.safe-bottom-sheet` CSS class                                                           |

### 2. DataTable → Card Reflow on Mobile

**Before**: Data tables rendered with `overflow-x-auto` on mobile, requiring horizontal scrolling through many columns. Unusable for touch interaction.

**After**: Below `md` (768px), table view automatically displays as stacked cards. First column becomes the card title, second becomes subtitle, status columns render as badges, and up to 3 additional columns render as key-value pairs. Row actions appear as a kebab menu. Full card is tappable.

| Aspect           | Detail                                                               |
| ---------------- | -------------------------------------------------------------------- |
| File             | `list-page-view-content.tsx`                                         |
| Threshold        | `md` (768px) via `useBreakpoint()`                                   |
| Status detection | Auto-detects columns with `status` in id or `fieldType === "status"` |
| Touch feedback   | `active:scale-[0.98]` on cards with `motion-reduce` guard            |

### 3. Toolbar Actions Collapse on Mobile

**Before**: FilterBar showed all action buttons (search, filters, column visibility, view switcher, refresh, import/export, create) at all breakpoints, resulting in crowded, wrapping toolbars.

**After**: On mobile, secondary actions (column visibility, view switcher, refresh, import/export) are hidden. Only search, advanced filters, and create (icon-only) remain visible.

| Aspect        | Detail                                                |
| ------------- | ----------------------------------------------------- |
| File          | `list-page-shell.tsx`                                 |
| Method        | `hidden sm:contents` CSS on secondary actions wrapper |
| Create button | Full label on desktop, icon-only (Plus) on mobile     |

### 4. Confirm Dialog Button Stacking

**Before**: Confirm/Cancel buttons rendered side-by-side at all breakpoints, with small touch targets on mobile.

**After**: On mobile, buttons stack vertically (`flex-col-reverse`) with the cancel button on top (easily reachable) and primary action below (intentional).

### 5. Mobile Input Keyboard Optimization

**Before**: Form fields rendered without `inputMode` attributes, causing mobile browsers to show the generic text keyboard for specialized inputs.

**After**: All form fields now declare appropriate `inputMode`:

- `email` → email keyboard (with `@` and `.`)
- `tel` → phone number pad
- `url` → URL keyboard (with `.com`, `/`)
- `number` → decimal keypad

### 6. Offline Network Banner

**Before**: Network status indicated only via a small icon in the topbar (`ConnectionIndicator`), easy to miss on mobile.

**After**: New full-width `OfflineBanner` component renders between topbar and content when the browser goes offline. Shows "You're offline — changes will sync when reconnected" with a dismiss button. Auto-reappears on new offline events.

### 7. Topbar Icon Density Reduction

**Before**: ThemeSwitcher always visible in topbar, contributing to icon overflow on very small screens.

**After**: ThemeSwitcher hidden below `sm` breakpoint. Available via Settings on mobile.

## Phase 2 Enrichments (Gesture Layer)

### 8. Swipe-to-Close Bottom Sheets

**Implementation**: `@use-gesture/react` `useDrag` with vertical axis lock on mobile. Rubber-band resistance during drag, velocity-based fling detection for quick dismissals, and haptic feedback at threshold crossing. Desktop unchanged.

| Aspect     | Detail                                                        |
| ---------- | ------------------------------------------------------------- |
| Files      | `dialog.tsx`, `confirm-dialog.tsx`, `use-swipe-to-dismiss.ts` |
| Threshold  | 80px drag or 0.5px/ms fling velocity                          |
| Resistance | 0.4 rubber-band factor                                        |
| Haptic     | `hapticImpact()` at threshold                                 |

### 9. Pull-to-Refresh on List Pages

**Implementation**: `PullToRefresh` wrapper component around `ViewContent` in `list-page-shell.tsx`. Uses `@use-gesture/react` vertical drag with scroll-top detection (only activates when scrolled to top). Damped pull with animated spinner.

| Aspect    | Detail                                           |
| --------- | ------------------------------------------------ |
| Files     | `pull-to-refresh.tsx`, `list-page-shell.tsx`     |
| Threshold | 80px pull                                        |
| Callback  | `invalidateEntity()` (re-fetches data)           |
| Spinner   | `Loader2` rotation proportional to pull distance |

### 10. Swipe-to-Reveal Row Actions

**Implementation**: `SwipeRevealCard` wrapper in `MobileListCards`. Swiping left reveals action buttons behind the card (120px reveal width). Single-reveal pattern: opening one card auto-closes any other. Spring-animated snap positions.

| Aspect       | Detail                                          |
| ------------ | ----------------------------------------------- |
| File         | `list-page-view-content.tsx`                    |
| Reveal width | 120px                                           |
| Snap         | Velocity fling (>0.3px/ms) or 40% threshold     |
| Actions      | Dynamically sourced from `renderRowActionItems` |

### 11. Long-Press Context Menu

**Implementation**: 500ms touch-and-hold on mobile cards triggers the kebab DropdownMenu via ref click. Cancelled if finger moves. Haptic feedback (`hapticSelection()`) on activation.

| Aspect   | Detail                               |
| -------- | ------------------------------------ |
| File     | `list-page-view-content.tsx`         |
| Duration | 500ms                                |
| Cancel   | On touch move                        |
| Haptic   | `hapticSelection()` (50ms vibration) |

### 12. Haptic Feedback System

**Implementation**: `src/lib/haptics.ts` provides five semantic patterns via the Web Vibration API. All methods silently no-op on desktop/unsupported browsers.

| Pattern             | Duration     | Usage                   |
| ------------------- | ------------ | ----------------------- |
| `hapticTap()`       | 10ms         | Button presses, toggles |
| `hapticSuccess()`   | [10,30,10]ms | Confirmations, saves    |
| `hapticWarning()`   | [30,20,30]ms | Destructive actions     |
| `hapticSelection()` | 50ms         | Long-press activation   |
| `hapticImpact()`    | 20ms         | Threshold crossings     |

### 13. iOS PWA Splash Screens

**Implementation**: Generated 13 device-specific PNG splash images (320–2048px) via `scripts/generate-splash.mjs`. Added `apple-touch-startup-image` link tags with `device-width`/`device-height`/`-webkit-device-pixel-ratio` media queries for each iOS device variant.
