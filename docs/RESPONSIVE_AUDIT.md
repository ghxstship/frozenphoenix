## Audit Methodology

Every route and component was audited against the 6 canonical breakpoints:

- **xs** (320px) — iPhone SE, small Android
- **sm** (640px) — Large phones, landscape
- **md** (768px) — Tablets portrait
- **lg** (1024px) — Tablets landscape, small laptops
- **xl** (1280px) — Standard desktop
- **2xl** (1536px) — Large desktop

## Issues Found & Resolved

### Critical

| #   | Issue                                                                                                                                           | File         | Breakpoint | Fix                                                           |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | ---------- | ------------------------------------------------------------- |
| 1   | **Viewport meta missing `viewport-fit=cover`** — notched devices (iPhone Dynamic Island, Android cutouts) would render content behind the notch | `layout.tsx` | All        | Added `viewport-fit=cover` to viewport meta tag               |
| 2   | **Input font size < 16px** — `.text-sm` (14px) on `Input` caused iOS Safari to auto-zoom on focus, making forms unusable                        | `input.tsx`  | xs, sm     | Changed to `text-base sm:text-sm` (16px mobile, 14px desktop) |

### Major

| #   | Issue                                                                                                                                             | File                            | Breakpoint | Fix                                                                               |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- | ---------- | --------------------------------------------------------------------------------- |
| 3   | **Apple PWA meta tags missing** — no `apple-mobile-web-app-capable`, no status bar style, no touch icon                                           | `layout.tsx`                    | All (iOS)  | Added all required Apple meta tags                                                |
| 4   | **PWA icons insufficient** — only SVG icon, no PNG raster icons for Android install prompts or iOS home screen                                    | `manifest.json`                 | All (PWA)  | Generated 180/192/512px PNGs + maskable variant                                   |
| 5   | **Dialog not bottom-sheet on mobile** — centered modal at all breakpoints, wasting mobile screen real estate and not following mobile UX patterns | `dialog.tsx`                    | xs, sm     | Refactored to bottom-sheet with slide-up animation on mobile, centered on desktop |
| 6   | **Confirm dialog not mobile-optimized** — centered overlay with desktop-only scale animation                                                      | `confirm-dialog.tsx`            | xs, sm     | Bottom-sheet on mobile, slide-up animation, stacked buttons                       |
| 7   | **DataTable unusable on mobile** — tables rendered with `overflow-x-auto` only, requiring horizontal scrolling                                    | `list-page-view-content.tsx`    | xs, sm     | Added `MobileListCards` component with automatic card reflow below `md`           |
| 8   | **Select zoom on iOS** — both custom Select trigger and native form select used `text-sm` causing auto-zoom                                       | `select.tsx`, `form/select.tsx` | xs, sm     | Changed to `text-base sm:text-sm`                                                 |
| 9   | **Topbar icon density** — ThemeSwitcher visible on all breakpoints, crowding mobile topbar                                                        | `topbar.tsx`                    | xs         | Hidden below `sm`, available in Settings                                          |
| 10  | **Toolbar actions overflow** — column visibility, view switcher, refresh, import/export all visible on mobile, crowding FilterBar                 | `list-page-shell.tsx`           | xs, sm     | Wrapped in `hidden sm:contents`; create button is icon-only on mobile             |
| 11  | **No offline awareness** — `ConnectionIndicator` showed icon-only in topbar, no persistent banner                                                 | New component                   | All        | Created `OfflineBanner` with full-width banner, dismissible, auto-reappears       |

### Minor

| #   | Issue                                                                                                | File                        | Breakpoint | Fix                                                                     |
| --- | ---------------------------------------------------------------------------------------------------- | --------------------------- | ---------- | ----------------------------------------------------------------------- |
| 12  | **No `inputMode` on form fields** — mobile keyboards not optimized for email/tel/url/number inputs   | `form-page-shell.tsx`       | xs, sm     | Added `inputMode` attributes for email, tel, url, decimal               |
| 13  | **No `overscroll-behavior: contain`** — iOS rubber-banding bled through dialog/overlay backgrounds   | `globals.css`, `dialog.tsx` | xs (iOS)   | Added `.overscroll-contain` utility + applied to dialog content         |
