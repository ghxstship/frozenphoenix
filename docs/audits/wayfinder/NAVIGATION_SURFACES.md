## 1. Breadcrumbs

| Aspect | Status | Details |
|--------|--------|---------|
| **Present on all pages?** | ✅ Yes | Generated by `getNavigationBreadcrumbs()` in topbar, renders via `EntityBreadcrumb` component |
| **Consistent?** | ✅ Yes | Always present in topbar, algorithm-driven from URL path segments |
| **Hierarchy vs path-based?** | Hybrid | Reflects URL hierarchy; attempts to match nav labels via `getNavigationLabel()`, falls back to `formatPathSegment()` |
| **Clickable at every level?** | ✅ Yes | Each segment is a `<Link>` |
| **Max depth observed?** | 4 | e.g., `/live-ops/crew/[id]/details` |
| **Entity context?** | ✅ Yes | `EntityBreadcrumb` component resolves entity names from URL segments |

### Issues
- ⚠️ Dynamic segments (e.g., `/events/[id]`) show raw IDs until `EntityBreadcrumb` resolves the entity name — may flash briefly.
